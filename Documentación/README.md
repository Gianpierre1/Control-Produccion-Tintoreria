# Documentación del proyecto

Repositorio para análisis y desarrollo de herramientas
para los procesos de Tintorería y Acabados.

## Objetivo

Centralizar información, scripts y análisis relacionados
con la producción textil.

## Proyecto Costura: tiempos improductivos

Documentación en [`Documentación/costura/`](costura/):

- [00-brief-tecnico.md](costura/00-brief-tecnico.md): objetivo, fórmulas, estados, arquitectura, preguntas abiertas.
- [01-hardware-modelos.md](costura/01-hardware-modelos.md): modelos concretos y cantidades.
- [02-integracion-y-red.md](costura/02-integracion-y-red.md): red PoE, distribución de switches, opciones de conexión y de botones.
- [03-app-tablet.md](costura/03-app-tablet.md): **enfoque vigente**: app Android por costurera, tickets generados por el sistema, API y cálculo de minutos.
- [04-informacion-pendiente.md](costura/04-informacion-pendiente.md): lo que falta saber (SQL Server, decisiones de negocio) y plantilla para responder en `05-respuestas.md`.

Código en `Scripts/costura/` (esquema SQL y fórmulas con tests).
